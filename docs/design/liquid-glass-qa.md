# 液态玻璃 UI 重建验证

验证日期：2026-10-10。

## 材质与界面范围

首页、视频库的时间线/文件夹/日历/收藏、设置、视频详情及播放器共用缓慢漂移的低饱和彩色背景。蓝、灰紫、浅桃和灰绿色以两层大面积柔和渐变交叠，分别以 42 秒和 54 秒缓动往返。背景固定在内容下方，忽略指针事件，不占用布局空间；内嵌播放器不重复绘制背景。页面隐藏时暂停漂移，减少动态效果时保持静态。

导航与菜单采用 24px 背景模糊、半透明填充、单层柔和边框与轻阴影。设置页字段保留半透明填充，避免每个输入框重复模糊。日期与时间轴预览气泡采用 36px 模糊和 88% 不透明度，增强文字可读性。移除了边缘位移折射、双层描边、指针高光和强烈回弹。选中胶囊用 220ms 平滑过渡，按钮轻微缩小至 98.5%，菜单用 200ms 淡入并上移 4px，关闭用 140ms 淡出。快速开关从当前状态衔接，减少动态效果时立即切换。

这是网页材质实现。不支持背景模糊时采用实色控件，减少透明度及高对比度模式同时关闭彩色背景。本轮在 Chrome 验证，没有执行 Safari/Firefox 实机检查。此前移除的装饰 logo、重复图标、宣传文案和重复统计保持简洁；保留视频元数据、功能提示、操作状态及设置说明。

## 合并导航

首页、时间线、文件夹、日历和收藏共用一组导航胶囊。移除第二组视频库视图胶囊及重复的收藏入口；当前视图在唯一的导航中高亮。视频库视图沿用原有 URL 生成逻辑，切换时保留视频类型、时长、画幅和日期筛选。首页、设置、详情页使用同一导航；工具栏只保留统计、预览大小、筛选和扫描。手机五个入口同排显示，矮屏宽度足够时使用紧凑单行页头。

## 密度时间轴

使用服务端完整、已筛选的每日记录索引，而非当前已加载的卡片数量。每日权重为 `sqrt(max(1, count))`，将累计权重映射到 0–1000 的轴坐标，拖动时通过二分查找对应日期区间。记录多的日期分配更长区间，年份长度由该年份各日期权重累计决定，无记录的日期不插入空白轴段。平方根权重避免特别密集的一天过度挤占稀疏日期。

密度色带、日期刻度、当前位置、年份标签与鼠标/触摸预览共用同一映射。收藏变化更新刻度。年份标签重叠时隐藏相邻标签，所有日期仍可通过轴拖动、方向键、PageUp/PageDown、Home/End 到达。最旧记录后的占位空间纳入网格，使固定时间轴在末尾仍完整可见。

## 扫描、边界与滚动修复

扫描通过 JSON 请求启动，提交失败可以重试，进行中禁用重复提交；完成后刷新原视图并恢复时间线位置。播放器展开时推迟刷新，关闭后再更新列表。普通表单提交也回到同源的视频库或首页视图并保留筛选，外部来源无法改变返回目标。后台维护繁忙时不重复启动任务。

恢复内网状态下的浅色彩虹流动边框，外网与内嵌播放器不显示该边框。时间轴去掉底部收藏图例；年份标签根据实际高度限制上下边界、隐藏重叠项，取消播放器展开时继承的 52px 窄宽限制，并给四位年份留下完整文字空间。

设置页缓存分组位置，将滚动事件合并到每帧，只有当前分组变化时才写入导航状态。移除表单字段和嵌套控件的独立模糊，以及大面积背景的额外 60px 模糊，缩小背景绘制面积，仍保留缓慢的低饱和彩色漂移。Chrome 4 倍 CPU 限速下，相同的 90 帧上下滚动采样，实时背景模糊图层由 30 减到 6，导航属性写入由 100 减到 18；两轮平均帧间隔都约 16.6ms，没有超过 50ms 的帧。该测量证实了重复工作减少，不代表所有设备上的帧率保证。

## 加载、播放与切换修复

首页和视频库使用流式 HTML，先发出不依赖外部资源的加载骨架，再在线程中读取列表并生成页面；响应关闭代理缓冲。共享样式和脚本在读取列表期间开始预载。样式以非阻塞方式加载，页面脚本并行预载，按依赖顺序在样式就绪后执行。初始时间轴日期恢复也纳入加载阶段；初始化完成后再淡出骨架。资源或列表加载失败时提供重新载入。无 JavaScript 时通过 noscript 样式保留普通页面。

内网预检使用相同的轻量加载界面，保留继续访问当前地址的入口，不再显示独立的检测说明页面。导航点击立即移动选中胶囊并显示目标页面的占位布局，经过两帧绘制后发起跳转；返回播放器时保留替换历史记录的行为。移除旧导航下划线，预览尺寸在样式初始化前读取，页面资源加载期间不会展示旧样式。

播放器先确定最终网格与时间轴布局，再以透明度和位移做合成动画，取消逐帧改变网格宽度的动画；关闭时先淡出播放器，再更新布局。首页与视频库统一采用宽高比大于 4:3 时内嵌播放，否则打开完整播放页。首页展开时保持点击视频的位置，支持分隔条拖动及键盘调整，保留收藏、视频设置与关闭控件。快速关闭再打开不会清空新的播放器。首页扫描完成时也延后刷新至播放器关闭，并保留随机组。

随机视频换组立即显示忙碌反馈，固定原有最小高度，在后台请求和预解码封面后淡出淡入，失败时保留原组并允许重试。时间轴气泡离开时保持原位置完成淡出，避免被当前日期重新定位。内网彩虹边框将峰值透明度从 26% 调整为 40%，向内 12px 渐隐。

首页封面失败数量可打开模态小窗，列出未被标记为缺失的视频名称、路径和失败原因，每批 50 个；支持继续加载、失败重试、Escape 关闭和点击进入视频设置。关闭时取消请求，快速重新打开不会混入旧响应。

## 验证结果

- Python 全量检查：`python -m pytest -q`，149 项通过。覆盖扫描 JSON 响应、重复启动和普通表单返回视图。已有 FastAPI `on_event` 弃用警告。
- JavaScript：`node --test tests/*.test.cjs`，16 项通过，包括扫描提交、失败重试、状态轮询、隐藏页面暂停，以及内网地址解析以及密度区间比例、年份分配、区间边界、空索引、单日与等密度情况。
- Chrome 浏览器：1440×1000、390×844、320×480、320×568、768×1024、1280×720、1100×700、568×320、844×390。
- 首页、时间线、文件夹、日历、收藏、设置和详情在桌面/手机没有文档横向溢出；主导航固定为五个入口，不再出现第二组视图导航。
- 使用独立临时数据库中的 232 条示例记录，确认首批 180 条追加至 232 条；End 跳转至 2006-01-01，Home 返回 2026-10-08，跨批次加载后滑块日期一致。
- 浏览器验证扫描期间 URL 保持原视图，扫描完成时播放器持续打开，关闭后仅刷新原视图，并恢复筛选后最旧日期 2025-03-05；错误响应可重试。
- 日期气泡模糊和填充检查、年份在播放器展开/关闭/悬停时的边界检查、内网彩虹边框及减少动态效果模式检查通过。
- 内嵌播放器打开、关闭通过；矮屏与最旧日期处，时间轴边界位于视频库滚动容器内。
- 验证背景渐变缓慢漂移、磨砂背景模糊、选中胶囊移动、轻微按压反馈、鼠标/键盘开关菜单、快速关闭再展开、减少动态效果与高对比度模式。
- 桌面、手机及预览大小改变后，同一行封面高度一致。使用实际浮点宽度计算网格，避免整数舍入使一张封面错误换行。
- 播放器画质菜单箭头保留，画质菜单反复开关、中心按钮按压位置及播放调节展开通过；本轮没有使用示例记录执行真实媒体播放。
- 首页换组操作完成后恢复“换一组”，不再输出修饰性成功文案。
- 额外验证外部样式延迟 1.8 秒时仍显示加载首帧；列表读取前已发送骨架。导航响应延迟时，点击后立即显示占位和胶囊移动。
- 桌面播放器展开动画采样 22–25 帧，iframe 宽高保持稳定；首页 390×844、844×700 使用完整播放页，568×320 使用内嵌播放。
- 真实示例失败列表、小窗请求取消与重新打开、错误响应重试、随机组切换、浏览器返回、减少动态效果，以及首页扫描延后刷新/保留随机组检查通过。
- 浏览器无 JavaScript 页面异常。
- `git diff --check` 通过。
