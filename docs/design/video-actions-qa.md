# 视频下载、随机排除与全屏验证

验证日期：2026-10-10。

## 行为

- 完整播放页和内嵌播放器都提供下载菜单，下载画质独立于播放画质。
- 原画下载原始文件；超清、高清、流畅复用既有分辨率与码率配置，生成完整 MP4 后下载。同一缓存的并发请求只执行一次转码，转码失败或超时不会留下可下载的半成品。
- 首页随机菜单统一使用紧凑磨砂面板、图标、分隔线和键盘焦点样式；收藏与时间线复用同一菜单组件。支持右键、长按、Shift+F10、方向键及 Escape。
- 首页“不再出现在随机中”只设置随机排除；时间线“不参与随机与每日”同时设置随机与每日回忆排除。已经单独排除随机的视频仍可进一步排除每日回忆；时间线提供恢复参与入口。
- 排除字段自动迁移到既有 SQLite 数据库，视频仍保留在时间线、收藏和最近记录中。每日回忆首页及完整列表均使用排除字段。
- 首页缓存只保存视频 ID，服务端重新校验并补充有效候选。浏览器恢复缓存页面时，即使会话缓存已被清除，也会校验当前卡片，避免已排除的视频重新出现。
- 全屏按视频实际画幅计算画面尺寸，保留完整画面并居中。全景画布继续占满可用区域；全屏取消根元素滚动条占位。展开播放调节后自动重新计算可用高度。

## 浏览器结果

使用本机 Chrome、独立临时数据库与测试媒体，不读取或修改实际视频库。

- 菜单打开、键盘选择、Escape 关闭、屏幕边缘定位、随机排除与恢复参与均通过。
- 旧版随机 HTML 缓存的 ID 会重新校验；模拟浏览器恢复缓存页面后，排除视频会移出随机列表。
- 完整页的高清下载及内嵌页的原画下载均收到浏览器下载事件，文件名与文件内容正确；下载不会触发页面导航加载界面。
- 390 × 844 手机布局没有横向溢出，下载菜单仍可访问。
- 1996 × 1248 全屏中，16:9 画面为约 1873.77 × 1054，水平居中，无横向溢出或滚动条占位；全景画布与可用区域等宽。
- 使用浏览器生成的 400 × 300 WebM 验证真实视频元数据。内嵌全屏画面为约 1074.66 × 806，展开播放调节后变为约 989.33 × 742，始终保持 4:3；手机全屏同样保持实际比例。
- 长按打开菜单通过；保存接口失败时显示重试提示并保留当前视频卡片。
- 页面没有未捕获 JavaScript 异常。

本机没有完整 FFmpeg 可执行程序，转码下载测试使用生成器替身验证完整文件、并发缓存和错误处理；既有 FFmpeg 命令配置测试通过。真实视频播放与全屏比例使用浏览器生成的 WebM 验证。
