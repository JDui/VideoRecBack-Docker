# VideoRecBack v2.7.12

- 统一 GUI 的稳定浅底、轻磨砂导航及分级圆角，工具栏控件桌面 36px、手机 44px，窄窗口自动换行。
- 首页调整为随机视频主区、近期记录侧栏及收藏/那年今日分组；竖屏在同一个随机模块中完整展开三张，保留「换一组」。
- 收敛持续背景动效，保留媒体原色，改善设置保存栏和窄播放器分栏的可读性。
- 显示比例恰好为 9:16、1:2 的竖屏封面改为三帧横排，兼容手机旋转方向；其他窄竖屏继续四帧横排，接近方形继续四宫格。
- 时间线初始比例与封面布局共用规则，维护工具说明同步更新。

## 安装与升级

附件适用于 **linux/amd64**。

```sh
docker load -i videorecback-2.7.12-amd64.tar
```

将 Compose 镜像更新为 `videorecback:2.7.12`，保留原有配置和数据挂载，再执行 `docker compose up -d`。

已有竖屏封面会继续使用缓存。升级后可通过「设置 → 维护工具 → 重载竖屏缩略图」更新为新布局，失败项保留旧封面。

桌面、手机及窄分栏 GUI 使用隔离示例库验证；截图见仓库的 GUI 实施验收记录。真实触控设备、完整辅助技术、实际视频解码和 HDR 显示不在本轮通过范围。
