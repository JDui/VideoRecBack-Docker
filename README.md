# VideoRecBack

VideoRecBack 是一个面向 NAS 视频存档的容器化浏览器。它把设置存到 `/config`，把 SQLite 数据库和 webp 缩略图缓存存到 `/data`，视频目录通过 Docker volume 只读挂载到容器内路径。

## 功能

- 独立首页提供“随机视频”（随机三个视频，可换组）、“最近记录”、“收藏”、“那年今日”和“影像库概览”；首页只读取数据库和缓存封面，不遍历视频目录。“那年今日”按服务端本地日期与视频文件时间匹配往年同月同日的记录，最近记录按文件时间排序。
- 视频库可通过 `/library` 或原有 `/?view=timeline` 等链接进入；时间线只读取数据库和缓存图，不遍历视频目录；视频卡片按 180 条分批加载，左侧时间线统计保持完整并支持跨批次跳转。
- 首页、时间线、文件夹、日历和收藏合并在同一组主导航中，当前页面统一高亮；切换视频库视图保留筛选条件。视频库工具栏仅显示统计、预览大小、筛选和扫描，筛选作为二级菜单打开。
- 手动扫描在后台提交，不跳回首页；完成后保留当前视图、筛选与时间线位置。内嵌播放器打开时延后刷新，关闭后更新列表，启动失败可重试。
- 视频库支持按类型、时长、画幅筛选，并可用滑条调节封面预览大小；日历视图默认从年视图进入。
- 平面视频显示为 4:3 胶片卡片，封面按设置的 480P/576P/720P 高度生成 4 个时间点合成的 webp 四宫格；10bit 视频会在封面右下角显示黄色 10bit 标记，历史记录会在下次播放入口懒检测一次并写入数据库。
- 全景视频显示为 4:3 卡片内的球面预览，封面优先取中点，失败后按多个时间点重试，并按设置的 480P/576P/720P 高度生成 webp 鱼眼球面预览；带全景标记或宽高接近 2:1 的视频会默认识别为全景，10bit 全景视频同样会显示 10bit 标记。
- 点击封面直接播放，右键或长按封面进入该视频设置。
- 播放页可收藏视频，首页和视频库的导航提供收藏入口；收藏页中右键或长按视频可跳转到时间线位置或进入视频设置。
- 页面宽高比大于 4:3 时，点击封面会在右侧展开内嵌播放器，默认占可用宽度的 2/3，并可拖动分隔条调整列表和播放器宽度比例；分隔条支持方向键微调、Home 或双击恢复默认比例；宽高比不大于 4:3 时会跳转到完整播放页，关闭后会恢复原列表位置。
- 播放页优先适配视口高度，窄小屏幕可滚动访问全部控件，画质放在紧凑标题栏的下拉菜单中，可在原画、超清、高清和流畅之间切换，并可在设置中分别选择平面/全景默认画质；原画直接走原始媒体路由推流，超清保持原分辨率并使用 8mbps HLS 分片串流，高清生成最高 1080P/3mbps HLS 分片串流，流畅生成最高 720P/1mbps HLS 分片串流，切换时会从当前时间点边转码边续播并保持原视频长宽比；10bit 原画在当前浏览器无法直接播放时会自动切到超清 HLS 转码保底播放；播放器会在缓冲卡住时重开当前画质并恢复播放，HLS 暂停和页面短暂隐藏不会立刻删除当前转码流；平面视频的进度、音量和按钮控件位于画面外的紧凑控制栏，全屏时仍保留控制栏，全景视频同样提供播放按钮、快进快退、全屏、底部进度滑条、音量滑条、状态描边、拖动、触控板双指滑动、触屏双指缩放和触控板缩放来控制视角与视野，双击全景播放器可全屏。
- 界面使用缓慢漂移的低饱和蓝、紫、桃色和灰绿色背景；导航、按钮、输入框与菜单采用磨砂半透明材质。移除装饰 logo、重复图标、宣传文案和重复统计；选中胶囊平滑移动，按钮轻微按压，菜单短距离淡入淡出。页面隐藏时暂停背景动画，手机和矮屏幕自动压缩工具栏。时间轴根据完整索引中每日视频数量的平方根分配长度，密集日期和年份展开，稀疏区域压缩，支持拖动、方向键和 Home/End 跳转；收藏标记同步更新。竖屏播放页使用完整标题、沉浸画面和底部控制面板，倍速/曝光收纳在可展开的播放调节中。内网访问恢复浅色彩虹流动边框。时间轴预览气泡使用更厚的磨砂填充，年份标签约束在轴内，底部不再显示收藏图例。设置页缓存分组位置并按帧更新导航，表单保留半透明填充而不叠加独立背景模糊。界面支持减少动态效果、减少透明度和高对比度偏好，不支持背景模糊的浏览器使用实色控件。
- 设置页采用左侧分组导航、双列表单与底部固定保存栏，按视频库、播放偏好、封面与转码、内网连接、维护工具分组；保存后留在设置页并显示结果。设置页可调整页面标题、目标路径、按小时计的扫描间隔、默认播放音量、平面/全景默认画质、封面分辨率、平面/全景 HLS 转码编码器、HLS 最大缓存占用、内网直连、视频扩展名、忽略点开头文件/目录、忽略文件名规则、日期/大小/时长显示项，并可执行 2MB 样本的服务器连通测试；需要二次确认的刷新封面、全景重校验和重校验全部视频数据集中在同一个操作框内，其中全部视频数据重校验会重新记录 10bit、色度采样和平均码率；浏览器会自动探测设置的内网服务，受浏览器安全策略阻止时可点击“检测内网”，通过一次性顶层导航握手确认后再显示“跳转内网”；扫描间隔为 0 时关闭自动全盘扫描，默认播放音量会同步写入数据库。
- 播放前不访问原视频文件；只有手动扫描、开启的自动扫描、增量文件/文件夹扫描和播放路由会读取视频目录。
- 全盘扫描使用文件时间纳秒、大小和路径索引批量比较，未变化文件不写数据库；媒体分析与封面生成进入单并发后台队列，并限制 ffmpeg 线程数、增加任务冷却时间。媒体处理结果带持久版本，成功但缺少可选元数据的视频以及已达到重试上限的失败任务不会在普通扫描中反复入队；扫描状态会持续到媒体队列真正处理完成。SQLite 使用低同步开销、短 WAL 自动检查点和 32MB 日志上限，降低数据库盘的持续写入。
- 扫描发现视频文件已删除时，会同步删除数据库中的视频记录、对应缩略图缓存和串流缓存。
- 播放接口支持 HTTP Range，适合浏览器拖动进度条。

## Docker Compose 模板

```yaml
services:
  videorecback:
    image: videorecback:2.6.11
    container_name: videorecback
    ports:
      - "8080:8080"
    volumes:
      - ./config:/config
      - ./data:/data
      - /path/to/nas/videos:/media:ro
    restart: unless-stopped
```

打开 `http://localhost:8080`，进入设置确认目标路径为 `/media`，然后点击扫描。

## 内网自动跳转

设置页的“内网连接”中可开启“载入前自动跳转内网”，对应 `/config/settings.json` 的 `intranet_auto_redirect_enabled`，默认 `false`。需要同时启用“内网直连检测”并填写内网服务地址、端口与协议。

开启后，首页、视频库、设置页和视频页面会先进行内网连通检测，成功后直接跳转，再加载页面内容、封面与播放器，并保留原路径、查询参数和锚点。检测失败或超过 1.5 秒会继续加载当前地址；浏览器安全策略阻止自动探测时，仍可通过“检测内网”确认连接，成功后自动切换。已经使用配置的内网地址时不会重复跳转。

## 全景封面调试

容器或本地环境可运行 `python -m app.thumbnails /path/to/panorama360.mp4 /tmp/thumb.webp --duration 120`，输出实际取帧时间、封面尺寸、亮度/对比度、有效性和每次重试原因。
